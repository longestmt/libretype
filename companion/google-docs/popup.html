LibreType for Google Docs

Checking the local app…

Open LibreType and enable its optional Google Docs companion.

In the current Google Doc, this button turns on screen reader and braille support. The popup closes while setup runs. Reopen it afterward to see the result. Other accessibility options stay unchanged. Setup currently recognizes English menus.

Manual setup

In Docs, choose Tools → Accessibility. Check “Turn on screen reader support” and “Turn on braille support”, then click OK.

This companion sends caret geometry and text fingerprints to LibreType on this Mac. It does not send document text or edit documents. Disable it in LibreType or remove this extension at any time.
